# FreeMAX Threat Model

## Что защищает FreeMAX

| Угроза | Защита | Риск |
|--------|--------|------|
| Закрытый код клиента | Открытый исходный код (MIT) | Серверная логика закрыта |
| Лишние разрешения | Только INTERNET (+CAMERA/AUDIO опционально) | Нет доступа к的местоположению, контактам, Bluetooth |
| Трекинг на стороне клиента | Нет Firebase, MyTracker, AD_ID, INSTALL_REFERRER | Серверные логи остаются |
| Перехват трафика | HTTPS + WSS (TLS 1.3) | MITM с сертификатом |
| Кража токенов | Android Keystore (AES-256) | Root-доступ обходит |
| VPN-детекция | Клиент не проверяет VPN | Сервер может определить VPN |
| Сбор данных об устройстве | Клиент не отправляет Build.MODEL,IMEI,etc. | web.max.ru может через JS (но мы не используем WebView) |

## Честное предупреждение

**FreeMAX меняет клиент, а не серверную инфраструктуру.**

MAX сервер ВСЁ РАВНО получает:
- IP-адрес клиента
- Метаданные сообщений (кто, кому, когда)
- Содержимое сообщений (текст, медиа)
- Информацию об устройстве через серверные логи
- Информацию о подключении (сеть,оператор связи)

## Что НЕ защищает FreeMAX

| Сценарий | Почему |
|----------|--------|
| Сервер читает сообщения | End-to-end шифрования нет |
| Сервер логирует IP | Это серверная функциональность |
| Бан аккаунта | MAX может заблокировать любой аккаунт |
| Изменение протокола | Сервер может изменить API в любой момент |
| Серверная аналитика | Мы не контролируем сервер |

## Рекомендации

1. **Использовать VPN** — скрывает IP от провайдера, но не от MAX
2. **Не хранить чувствительные данные** в чатах — сервер имеет доступ
3. **Регулярно обновлять** — следить за изменениями протокола
4. **Проверять код** — MIT позволяет верифицировать клиент
