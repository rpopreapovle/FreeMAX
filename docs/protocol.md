# MAX WebSocket Protocol

Протокол общения web.max.ru с сервером MAX.

## Транспорт

- **WebSocket**: `wss://api.oneme.ru/websocket`
- **Формат сообщений**: JSON
- **Бинарный сигналинг**: отдельный WebSocket для видеозвонков (WebRTC)

## Формат сообщений

### Запрос клиента

```json
{
  "seq": 1,
  "payload": {
    "method": <opcode>,
    "req": { ... }
  }
}
```

### Ответ сервера

```json
{
  "seq": 1,
  "payload": {
    "method": <opcode>,
    "resp": { ... }
  }
}
```

### Уведомление сервера (push)

```json
{
  "payload": {
    "method": <opcode>,
    "update": { ... }
  }
}
```

### Ошибка

```json
{
  "seq": 1,
  "payload": {
    "method": 0,
    "error": {
      "code": <error_code>,
      "message": "..."
    }
  }
}
```
