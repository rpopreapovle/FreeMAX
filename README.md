# FreeMAX

Открытый Android-клиент для MAX (ранее VK Messenger).

## Что это

FreeMAX — независимый клиент с минимальными разрешениями, без трекеров и
рекламы. Работает с официальным сервером MAX (`wss://api.oneme.ru/websocket`):
сообщения и метаданные по-прежнему проходят через сервер MAX, меняется только
клиент.

## Возможности

- чаты и группы, вложения, фото, видео, файлы и голосовые;
- ответы, пересылка, редактирование, удаление и реакции;
- непрочитанные, закреплённые чаты, поиск по чатам и сообщениям;
- профили участников, роли в группах, онлайн/последний визит;
- тёмная и светлая темы, настраиваемый размер текста;
- блокировка приложения PIN-кодом и локальный кэш с шифрованием.

## Установка

Скачайте APK со страницы
[Releases](https://github.com/rpopreapovle/FreeMAX/releases).

В публичных сборках отключено распознавание речи: для него нужен внешний
API-ключ, который не входит в APK.

## Сборка

```sh
git clone https://github.com/rpopreapovle/FreeMAX.git
cd FreeMAX
./gradlew assembleDebug
```

Для release-сборки и подписи см. [docs/release.md](docs/release.md).

Минимальная версия Android — 12 (API 31), целевая — Android 15.

## Лицензия

## Важно

Использование неофициального клиента может нарушать условия использования
MAX. Аккаунт могут ограничить или заблокировать, а серверный API может
измениться без предупреждения. Используйте на свой риск.
